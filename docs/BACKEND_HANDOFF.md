# Wagerie — remaining backend work

Reviewed: 22 October 2026.

Reference: [Wagerie Postman documentation](https://documenter.getpostman.com/view/19877378/2sBXqRjHFy).

This is a feature checklist based on the existing frontend screens and the published API documentation. It describes what remains to make those screens work with real data.

“Documented” means covered by the published Postman collection reviewed on this date. It does not mean a production payment or every edge case has been tested. Items not found in the collection are listed as documentation gaps, not proof that no backend implementation exists.

## What to work on next

Please first identify anything below that is already implemented but not included in the current Postman collection.

## Suggested working order

1. Share any already-built functionality missing from Postman, and resolve the frontend alignment items alongside it.
2. Finish the real account/payment journey and user receipt-confirmation feature.
3. Connect public winners/results and the admin overview to real information.
4. Complete catalogue-wide discovery and admin reporting, then run the shared launch checks.
